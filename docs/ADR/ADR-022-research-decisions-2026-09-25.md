# ADR-022 — 评分 4→9 的三项研究口径决定

状态：接受（用户 2026-09-25 授权由 Agent 按最合理方案确定）｜ 日期：2026-09-25

## 上下文

`docs/SCORE-2-TO-9-ROADMAP-2026-09-25.md` §3 列出三项必须先冻结的口径。不冻结，
G0 无法判定、G3 的“未查看 OOS”无法证明、组合层阈值无法计算。

## 决策 1：历史 PIT 采用「捕获 + 规则推定」双口径（方案 B）

- 每条研究输入必须带 `availability_basis`：`CAPTURED`（真实抓取时刻）或
  `RULE_DERIVED`（按下表冻结规则推定），报告分开统计，禁止混称。
- 规则（`ab_screener/research/availability_policy.py`，版本 `rule-v1`）：

| 数据集 | 推定可用时点 | 理由 |
|---|---|---|
| daily / daily_basic / moneyflow / adj_factor / 指数日线 | 交易日 T 18:00 | 供应商收盘后发布；取晚于常见发布时间的保守值 |
| top_list / top_inst（龙虎榜） | T 20:00 | 交易所盘后公布 |
| 财务（fina_indicator / 三表） | 实际公告日 `f_ann_date`（缺失用 `ann_date`）当日 23:59 | 公告可能盘后发布；只允许**首次披露版本**，无版本链的修订值一律 BLOCKED |
| stock_basic / 退市名单 | 上市日 / 退市日当日 00:00 | 事实日期 |
| cyq（筹码） | **仅 CAPTURED** | 供应商模型输出，历史值可能被重算，无法推定；且 2022-08~2026-08 已被探索 |

- 决策时点 `decision_at` 默认为次一交易日 09:15；`available_at ≤ decision_at` 才可用。
- 不回写数据库里的 `available_at`；推定值只在研究读取层计算并标注。

理由：只承认捕获（方案 A）会让任何历史研究永久不能过 G0，等于放弃 4→6；
按公告/发布时间推定是业界常规做法，只要规则事先冻结、保守、并与捕获数据分开报告。

## 决策 2：新机制与 OOS 封存

横盘突破家族（含筹码条件、中期动量过滤、双创配对）已在 G2/G3 失败，不再调参。
仓库中已有 `reversal_short` 因子与 `oversold_reversal_v1` SHADOW 插件，短期反转视为已被接触，**排除**。
选定三个本仓库从未实现或评估过、A 股文献有支撑、数据全部可用规则推定的机制：

| hypothesis_id | 机制 | 信号 |
|---|---|---|
| `H-20260925-max-lottery` | 散户彩票偏好：近期出现极端单日涨幅的股票被高估，随后收益偏低 | 过去 20 个交易日最大单日收益 MAX |
| `H-20260925-abnormal-turnover` | 注意力/情绪溢价：换手异常放大的股票被情绪推高，随后回吐 | 20 日平均换手 / 250 日平均换手 |
| `H-20260925-ep-value` | 价值溢价：A 股盈利收益率（EP）对收益有持续解释力 | 1 / PE（PE>0） |

- 预登记文档：`docs/prereg/` 下三份，冻结后由 SHA-256 锁定。
- **OOS 封存**：`2024-01-01 ~ 2026-09-25` 对三个假设封存（约 2.7 年，含 2024 年初小微盘急跌作为熊市段），
  配置 `configs/research/oos_seal.json`，由 `ab_screener/research/oos_seal.py` 在研究读取时强制；
  IS 为 `2016-01-01 ~ 2023-12-31`。每个假设只允许一次解封（写入追加式台账），第二次解封拒绝。
  2026-09-25 之后的前向数据自然未见，可作为 G6 前瞻。
- 只做多（A 股个股融券受限）：主统计为「最优五分位等权 − 全样本等权」，组合实现为最优五分位中前 30 只。

## 决策 3：组合「弱相关」阈值 = 两两月度超额收益相关 ≤ 0.5

- 相关以各机制多头组合相对全样本等权的**月度超额收益**计算（与 G2/G3 口径一致）；
- 0.5 以下才视为弱相关，允许进入 8 分组合；`ab_screener/research/scorecard.py` 中
  `MAX_MEMBER_CORRELATION = 0.5` 即此决定。
- 预期 MAX 与异常换手同属投机情绪类、相关可能偏高，因此另设价值机制分散。

## 后果

- 正向：G0 有了可判定口径；G3“未查看”由代码强制而非自述；三个机制可并行推进。
- 代价：规则推定可能比真实发布更晚（保守），会损失少量可用信息；封存期内不得对这三个假设查看
  2024 年后任何表现，包括画图和“看一眼”。
- 这三项决定不改变任何既有 FAIL 结论，也不影响每日选股参数。
