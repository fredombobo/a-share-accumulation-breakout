# V2-R 韧性吸收机制预登记（2026-08-29）

任务：`V2-P7.6-R-RESILIENT-ABSORPTION`

状态：**PRE-REGISTERED / RESEARCH ONLY / NO RESULT OBSERVED**

## 1. 为什么提出这个机制

当前生产一致口径在历史 OOS 仍有正收益，但正式研究门失败：PBO 偏高、DSR 与
MinTRL 覆盖不足、嵌套测试窗只有 2/5 为正。`attack_only` 市场状态变体又在 IS/OOS
同时亏损，因此本轮禁止继续移动市场状态阈值，也禁止把同一信号换一个环境标签后
重新搜索。

新假设来自不同的经济机制：**真正的吸筹平台不仅价格横盘，还应在系统性卖压出现时
表现出相对韧性，并在成交量加权后呈现正向价格压力；突破日收盘应落在当日价格区间
上半部，表明放量不是冲高回落。** 这检验的是平台内供给被承接，而不是市场状态。

## 2. 冻结定义

机制 ID：`RESILIENT_SUPPLY_ABSORPTION_V1`

基准信号与执行语义保持不变：

- 先满足生产 `A_POOL_STRICT_NEXT_OPEN_V1` 的严格横盘突破定义；
- 市场门禁继续使用生产一致的 `attack_and_neutral`，不改任何状态阈值；
- 信号在交易日 `t` 收盘后形成，最早只能在 `t+1` 可交易日开盘成交；
- 组合、成本、容量、停牌、涨跌停、T+1 和出场参数网格全部沿用当前权威版本。

对严格信号识别出的箱体（不含突破日），新增以下**全部必须满足**的固定判定：

1. **系统性卖压下的相对韧性**
   - 使用同一冻结 PIT 快照中的 `000300.SH` 日线；
   - 只取箱体内沪深 300 收益 `< 0` 的交易日；
   - 至少 4 个有效下跌日，否则证据不足并拒绝该信号；
   - 这些日期上 `个股收盘收益 - 沪深300收盘收益` 的中位数必须 `> 0`。
2. **成交量加权价格压力**
   - 箱体内每日日收益乘以 `当日成交量 / 箱体成交量中位数`；
   - 有效箱体收益至少 8 个、成交量中位数必须大于 0；
   - 上述乘积的算术平均必须 `> 0`。
3. **突破日收盘接受度**
   - `CLV = (2×close-high-low)/(high-low)`；
   - 当日必须有有效非零振幅，且 `CLV > 0`（收在当日区间上半部）。

边界 `0` 来自方向中性点，不形成可搜索阈值。最少 4/8 个观测只用于可识别性，
本轮不得测试 3、5、10 等替代值。缺日期、缺基准、缺量、非有限数、零振幅一律
fail-closed，不插值、不回退到当前行情或非 PIT 表。

## 3. 研究设计与污染披露

- 历史诊断固定使用当前自动 full 窗、600 只股票、步长 5、完整 54 组**原有出场参数**；
  新机制本身只有 1 个版本、0 个待搜索参数。
- 主要基线固定为 MA20/60，同时保留固定种子随机基线。
- 原 OOS 截止 2026-07-31 已被多轮研究观察。本轮历史结果只能用于**否证**或形成
  `HISTORICAL_SUPPORT_ONLY`，即使全部过门也不能单独清除 R 闸门。
- 本预登记时间之后第一个尚未观察的交易日才进入前瞻验证；按当前日历预计最早为
  2026-08-31，实际以交易所日历为准。此前 2026 年 8 月数据不得冒充 untouched OOS。
- 前瞻晋级至少要求 60 个真实完成交易日、30 笔已成熟成交且覆盖不少于 3 个自然月；
  未达到时 S/R 继续 `INSUFFICIENT` 或 `FAIL`。

## 4. 冻结门槛与停止规则

不降低 `ROBUST_PERSONAL_V2`：

- PBO `<= 0.20`；
- DSR `>= 0.95`；
- MinTRL coverage `>= 1.0`；
- 嵌套参数测试 5 窗且正收益比例 `>= 0.60`；
- OOS 净收益为正并击败预登记主基线；
- 2× 成本下候选净收益为正并击败同成本基线；
- 参数邻域覆盖率 100%，正超额比例满足现有门槛；
- 代码、PIT、组合、成本、市场门禁和本机制语义哈希齐全。

停止规则：

- 历史诊断任一正式硬门失败，结论为 `NO_CANDIDATE`，不得在本任务内修改机制阈值、
  删除条件或追加第二种机制重跑；
- 历史诊断全部通过，也只记为 `HISTORICAL_SUPPORT_ONLY`，生产 A 池仍使用 V1；
- 只有独立前瞻样本达到成熟度且通过同一门槛，才允许另开任务讨论候选晋级；
- 无论结果如何，`LIVE_TRADING_ENABLED=false`，不创建券商适配器、不生成真实订单。
