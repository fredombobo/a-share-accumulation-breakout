## 1. 机制

- 一句话：A 股散户占比高，投资者偏好“彩票型”股票（近期出现极端单日上涨），愿意为小概率大收益支付溢价，导致这类股票被高估、随后收益偏低（Bali-Cakici-Whitelaw 2011；A 股涨跌停制度下同样存在）。
- 反方解释：MAX 可能只是高波动/小市值的代理，已被剔除最小 30% 市值后仍可能被波动率解释；也可能因涨跌停截断而在 A 股减弱。
- 与已有失败假设的区别：不涉及箱体、突破、筹码或中期动量；横截面排序、月度再平衡。

## 2. 信号（冻结）

- `MAX20` = 形成日前 20 个交易日（含形成日）`pct_chg` 的最大值；有效交易日 < 15 天则缺失。
- 最优五分位 = **MAX20 最低**的五分位（预期超额 > 0）。
- G4 扰动：窗口 16 日、24 日。

## 3. 止损（除标尺止损外）

- IS 的 D 均值 ≤ 0 → 立即 FAIL，不解封 OOS。
- 若加入 20 日波动率作为控制后 D 符号翻转（描述性报告，不改变裁决，但必须写入结论）。
