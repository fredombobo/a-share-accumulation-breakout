# 预登记：H-20260925-ep-value（盈利收益率价值溢价）

> 口径：ADR-022；门禁：STRATEGY-SCORECARD-V0。本文件冻结后不得修改。

## 1. 机制

- 一句话：A 股投资者系统性高估成长叙事、低估稳定盈利，EP（盈利/价格）高的股票长期获得补偿（Liu-Stambaugh-Yuan 2019：A 股价值因子以 EP 最有效）。
- 反方解释：价值溢价可能是风险补偿（困境风险）而非错误定价；2019–2021 成长行情中价值长期跑输，可能在 OOS 期仍弱。
- 与已有失败假设的区别：纯基本面估值横截面排序，与量价形态无关；与 MAX/异常换手机制不同，预期相关较低。

## 2. 信号（冻结）

- `EP` = 1 / `daily_basic.pe`（静态市盈率，形成日值）；`pe ≤ 0` 或缺失的股票不入样本（亏损股单独不参与排序）。
- `daily_basic` 按 rule-v1 推定为 T 18:00 可用；PE 由供应商按当时已披露财报计算，不另读财务表。
- 最优五分位 = **EP 最高**的五分位。
- G4 扰动：EP 没有连续参数，改为形成日提前 1 个交易日、推后 1 个交易日各一次（检验对日期选择的敏感性）。

## 3. 止损（除标尺止损外）

- IS 的 D 均值 ≤ 0 → 立即 FAIL，不解封 OOS。
