# WP96 参数检查弹窗、真实结果图谱与界面精修计划

## 1. 目标

在 accumulation_breakout 的专业回测工作台内完成三项改造：

1. 参数空间检查成功或失败后，以可访问弹窗明确反馈结果和下一步。
2. 使用已经持久化的真实回测结果生成收益、回撤、参数分布和滚动复验图表。
3. 在不改变路由、字段顺序、回测口径和业务边界的前提下，统一回测页的视觉层级、间距、颜色语义和窄屏体验。

## 2. 设计与数据原则

- 产品仍是 AB-Screener 横盘吸筹突破研究平台，端口 8001。
- 保留每日选股、研究回测、使用说明三项发布信息架构。
- 设计语言为克制、可信、数据优先的个人金融研究工作台。
- 保留现有深浅主题和 ECharts，不新增 UI 或图表依赖。
- 参数检查弹窗不启动任务；关闭后仍保留页面内冻结预览。
- 图表只读取专业回测结果中的 IS、OOS、2 倍成本、双基线、WF 和排行榜数据。
- 当前接口没有完整每日净值序列，因此不得伪造净值曲线；图表必须明确口径和缺失状态。
- 缺失、无穷或非法指标不补零，不制造虚假盈利或稳定性。
- LIVE_TRADING_ENABLED 必须保持 false，不恢复纸面仿真或订单能力。

## 3. 实施范围

### 参数检查弹窗

- 成功态展示有效组合数、冻结股票数、动态预热天数、研究窗口和耗时提醒。
- 失败态展示结构化人话错误和返回调整动作。
- 使用 `role=dialog`、`aria-modal`、标题关联、初始焦点、Escape 关闭和焦点回归。
- 参数发生变化后清除旧预览，避免旧检查结果被误用。

### 真实结果图谱

- 收益对照：IS、OOS、2 倍成本、固定种子随机基线、MA20/60 基线。
- 风险收益分布：参数组合 OOS 净收益与最大回撤，点大小映射成交笔数。
- Top 参数：按当前排行榜顺序展示前十组合 OOS 净收益。
- WF 稳定性：有 `wf_detail` 时展示各窗口训练和测试 PF；字段不足时显示诚实的不可用说明。
- 每张图提供标题、口径说明、真实样本数和可读空状态。

### 视觉精修

- 统一回测页卡片、分组标题、数据强调、边界提示和结果区层级。
- 把入选参数从原始 JSON 改为人类可读参数摘要，技术身份继续保留在折叠详情。
- 桌面优先保持高信息密度，390px 自动改为单列且不横向溢出。
- 深浅主题语义一致；盈利用 A 股红色，亏损和回撤用绿色或明确文字，研究状态使用独立强调色。
- 尊重 `prefers-reduced-motion`，不加入无意义动画、渐变或装饰性大屏效果。

## 5. 验收标准

- 每次点击“检查参数空间”后都出现成功或失败弹窗，且不会静默启动回测。
- 成功弹窗能直接看到组合、股票、窗口和长耗时警告；关闭后页面内预览仍存在。
- 键盘可关闭弹窗，焦点返回原按钮，弹窗期间背景不被屏幕阅读器误操作。
- 已完成真实结果至少生成收益对照、参数风险收益分布和 Top 参数图；有 WF 明细时生成 WF 图。
- 所有图表值可从 API 返回结果逐项复算，不构造不存在的净值曲线。
- 缺失图表数据时有明确空状态，页面不崩溃，不把缺失值画成 0。
- 结果首屏仍明确结论、是否可启用以及不构成荐股；图表不能淡化 FAIL 或证据不足。
- 深色、浅色、桌面和 390px 均无横向溢出，键盘焦点清晰，控制台与页面错误为零。
- Vitest、Playwright、TypeScript 构建、Ruff、Mypy、严格架构检查和 Pytest 全部通过。
- 不重启正在运行的回测任务，不修改账本、扫描档案或生产策略参数。
