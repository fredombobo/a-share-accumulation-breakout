## 为什么不直接跑收益

财报报告期、公告日期、实际取得的数据版本是三件事。
今天查询到某份 2024 年报，不等于今天返回的每个数字在 2024 年就可用。
供应商此次确实返回过同一季度的不同实际公告日期版本；系统会按已知发布时间区分，
同一发布时间的冲突版本则拒绝使用。仍不能仅由这些有限样本证明完整的历史版本链。

本轮资格报告明确保持：

```json

  "status": "BLOCKED",
  "can_run_historical_experiment": false,
  "candidate_eligible": false,
  "return_experiment_executed": false
}
```
