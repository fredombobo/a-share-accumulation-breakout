# 小白使用手册（最少操作）

> 研究辅助工具，**不是投资建议**。

2026-09 个人版只用“每日选股＋研究回测”。不再跑纸面仿真；旧机构门禁不决定日常研究是否能用。详细操作见页面“使用说明”。

回测先点“检查参数空间”，看股票分层构成、数据及预热范围。检查通过后再启动。完成先看样本数和结论，再看“账户复盘”：逐日净资产、月度收益、逐笔费用。历史报告没保存的曲线不会补画；研究不通过也不会变成通过。

## 方式 A：丢给 AI Agent（最省事）

1. 打开 [PROMPT_FOR_AGENT.md](../PROMPT_FOR_AGENT.md)  
2. 把里面的提示词复制给任意 Agent，**只改成你的 Tushare Token**  
3. 等 Agent 说 `BOOTSTRAP_OK`，浏览器打开 http://127.0.0.1:8001/  
4. 点 **「扫描」**，看 **A 池**

你本人只需要：**提供 Token**。

## 方式 B：自己点 3 步

| 步骤 | 做什么 | 大约多久 |
|------|--------|----------|
| ① | 安装 Python 3.12（勾选 Add to PATH；已有可用的项目 .venv312 则不必再装） | 5 分钟，仅第一次 |
| ② | **双击 `一键启动.bat`**，按提示粘贴 Token | 首次建库 30～90 分钟；日常 2～10 分钟 |
| ③ | 浏览器打开后点 **「扫描」**，等结果 | 5～15 分钟 |

然后看 **A 池**（可关注的突破票）。**B 池**只是观察，别当主推。

停止：双击 **`停止.bat`**。

启动窗口的 Python 路径应为项目中的 `.venv312\Scripts\python.exe`。系统同时安装 3.14 也没关系，入口不会用它安装依赖。已有依赖通过本地检查后，不会每次联网重装。

若提示 `.venv312 不完整`，请保留旧目录并联系维护者修复，不要删除行情库或修改 Token。遇到 `mplfinance` 安装错误请更新项目依赖文件：已固定为 `0.12.10b0`，无需给所有包添加 `--pre`。

仅打开已有行情（不执行同步）：在项目目录运行 `一键启动.bat --skip-sync`。自动验收可加 `--no-browser` 并设置 `AB_START_NO_PAUSE=1`；普通双击无需这些参数。

## 现在只用两个业务入口

- **每日选股**：同步数据、运行扫描、看 A 池，再点进个股查看证据。
- **研究回测**：选择板块或股票，设置参数范围，先预览组合数，再运行 IS/OOS、滚动窗口、基线和成本压力。

侧栏还有 **“使用说明”**，这是站内说明书，不是新的业务模块。第一次使用先点它，里面按“今天做什么、系统为何这样判断、下一步点哪里”给出了完整路径。

旧单参数实验室、纸面交易和机构控制台已经从日用界面移除。研究回测的结果也不会自动进入 A 池。本系统是个人研究学习平台，不是机构荐股服务。

## 每只候选如何看 AI 评测

1. 在每日选股卡片点 **“AI 评测”**，或先点“查看详情”再点顶部 **“AI 证据评测”**。
2. 先看“支持证据”和“风险与缺口”。这部分来自本地数据库，不需要外部模型，也不会改动选股结果。
3. 需要更多文字解释时，再点 **“生成 AI 文字解读”**。模型未配置时按钮会显示“未配置”并禁用，本地评测仍然完整可用。

AI 结论只有“支持继续观察 / 证据混合 / 证据不足”，不会输出自动买卖指令。

## 研究回测：四步完成

1. 进入 **“研究回测”**。先选“细分行业、上市板块、地域”之一；不选分组代表全市场，可多选细分方向，也可直接填写股票代码。
2. 使用默认参数即可开始。默认会把“横盘最长天数”从 60 到 200 按 20 日步进，并搜索突破量比、止损、止盈与二次出货窗口；最长持有默认 30 日，也可单独步进。止损和止盈按百分比输入。“交易日采样间隔”是每隔 N 个交易日检查一次，越小越慢，默认 10。
3. 点 **“检查参数空间”**。检查完成后会弹出结果窗口，直接告诉你是否通过、有效组合数、冻结股票数、动态预热天数和研究窗口。这个弹窗只是运行前检查，不会自动启动回测。超过 512 组会提示可能耗时很长并在启动前再次确认；硬上限为 5,120 组。
4. 点 **“启动研究回测”**。切换页面或刷新后任务仍会恢复；完成后先看探索性结论，再看“结果图谱”和明细指标。

“结果图谱”包含五类真实结果：

- **净收益对照**：比较 IS、OOS、2 倍成本、随机基线和 MA20/60 基线。
- **Profit Factor 对照**：比较盈利总额和亏损总额的比例，PF 大于 1 才表示历史盈利覆盖历史亏损。
- **参数风险收益分布**：每个点是一条独立收益路径，纵轴是 OOS 净收益，横轴是最大回撤，点大小代表成交笔数。
- **独立路径前十的 OOS 收益**：精确折叠收益路径相同的等效参数，保持 IS 选出的原排名，不使用 OOS 再挑一次参数。
- **WF 窗口稳定性**：逐窗比较训练 PF 和测试 PF，判断跨时间稳定性。

图表只读取本次持久化的真实回测字段。当前专业结果没有逐日净值序列时，页面会明确说明并且不会伪造一条净值曲线；某类字段不足时也会显示“暂无可绘制数据”，不会拿 0 代替缺失值。

“最长持有”决定最迟何时退出，“二次出货观察窗”只决定量能累计检查范围。它们不是同一个参数。若页面显示“这是抽样研究”，说明采样间隔大于 1；要做逐日完整复验，请把间隔改为 1。

首页热力图和研究回测使用相同分类口径。细分行业适合看产业方向，上市板块用于主板、创业板、科创板，地域按公司注册地分组。它们都来自当前分类快照，只用于冻结本次股票池，不等同历史成员 PIT。申万、中信和概念板块在历史成分与数据时点未补齐前不会开放。筹码条件入口已经预留，但在经济机制预登记与数据覆盖完成前保持不可勾选。

## 怎么知道任务没有卡住

扫描、研究回测或行情同步开始后，页面顶部会固定出现“系统正在运行”。扫描和回测会显示当前阶段、百分比、已运行多久以及最近何时推进；切换页面、切出窗口或刷新都不会丢失。

如果连续 3 分钟没有任何真实进度变化，系统会提示“可能仍在重计算”，此时点 **“查看任务”** 检查即可，不要反复启动。行情供应商没有提供细分百分比时，界面只显示活动状态，不会编造一个百分比。

## 第一次用

1. 安装 [Python](https://www.python.org/downloads/)（安装时勾选 **Add python.exe to PATH**）
2. 解压/克隆本项目到任意文件夹
3. 双击 **`一键启动.bat`**
4. 窗口提示粘贴 **Tushare Token**（[tushare.pro](https://tushare.pro) 注册后在个人中心复制）
5. 等待「数据同步」跑完（第一次最久）
6. 自动打开网页：`http://127.0.0.1:8001/`
7. 点界面里的 **扫描**，喝口水等 5～15 分钟
8. 看 **A 池** 列表；点股票名可看 K 线

## 重要注意（请看完）

1. **没有 Token 拉不到数据** —— 一键启动会引导你填；也可编辑项目里的 `.env` 文件。  
2. **A 池 vs B 池** —— 只认真看 A 池；B 池条件更松，仅观察。  
3. **A 池是空的？**  
   - 若显示「防守」环境：市场偏弱，系统故意不让新开仓，**正常**。  
   - 若数据日期很旧：再跑一次一键启动同步。  
4. **不要把 `.env` 和 Token 发给别人 / 传到公开网盘。**  
5. **扫描要时间** —— 全市场约 5000 只，多核大概 **5～15 分钟**，别反复狂点。  
6. **本工具不荐股、不保证收益**；止损、仓位自己定。
