# 纸面交易平台 · 发布 / 回滚手册

版本：v1（阶段8）
关联：docs/PHASE8-ACCEPTANCE-2026-08-08.md

## 一、发布顺序（每次升级遵循）

1. **停止服务**：双击 `停止.bat` 或 `taskkill /F /PID <backend.pid>`
2. **备份**：`runtime/stock_data.db` + `runtime/portfolio.json` 复制到 `runtime/backups/acceptance_<date>/`
3. **迁移**：启动时自动执行增量迁移（`LocalStore.__init__` → `run_migrations`）；可手动预检：
   ```bash
   C:\Python314\python.exe -c "from paper_trading.migrations import run_migrations; run_migrations(r'runtime/stock_data.db', verbose=True)"
   ```
4. **离线质量门禁**：
   ```bash
   C:\Python314\python.exe -m pytest
   C:\Python314\python.exe -m ruff check .
   C:\Python314\python.exe -m mypy paper_trading web/backend_app.py
   npm --prefix web/frontend run build
   ```
5. **真实数据门禁**（需有效 TUSHARE_TOKEN）：
   ```bash
   C:\Python314\python.exe -m paper_trading.real_data_gate --days 730 --report runtime/gates/
   ```
   发布候选必须：最近 24 小时内、同一代码版本 + 配置哈希的 PASS 报告。
6. **构建前端**：`npm --prefix web/frontend run build`（或 `node node_modules/vite/bin/vite.js build`）
7. **完整重启**：核对 `/api/health` 的 `build_version` 与本地 `build_version.py` 一致
8. **纸面演练**：创建账户 → 预览/确认期初持仓 → 历史固定交易日执行一次完整日结
9. **观察期**：启用自动日终调度后至少观察 5 个交易日再视为稳定

## 二、回滚方式

| 场景 | 操作 |
|---|---|
| 纸面模块故障 | 环境变量 `PAPER_TRADING_ENABLED=false` 重启后端 → 纸面路由 503，调度器不启动 |
| 迁移后异常 | 停服后恢复 `runtime/backups/acceptance_<date>/stock_data.db`；迁移仅前向执行，v7 会在同一事务中保留数据并重建内部批次表约束，不反向删除业务数据 |
| 原持仓视图 | `portfolio.json` 全程只读，旧 `GET /api/portfolio` 只读兼容始终可用 |
| 账本错误 | **只允许追加冲正**（MANUAL 流水），禁止删除/重写已生成账本 |
| 真实下单 | `LIVE_TRADING_ENABLED` 恒为 false；代码中无任何券商下单适配器，回滚无需处理 |

## 三、关键配置开关

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `PAPER_TRADING_ENABLED` | true | false 时禁用纸面模块与调度器 |
| `LIVE_TRADING_ENABLED` | false | **恒为 false**，禁止改为 true |
| `TUSHARE_TOKEN` | 必填 | 真实数据门禁 / 日历落库需要 |

## 四、自动日终调度

- 交易日 16:15 后轮询（每分钟），每个账户/交易日最多成功执行一次
- 应用重启后自动补跑
- 手动补跑：`POST /api/paper/cycles/run`（走同一服务，不绕过数据/风险门禁）

## 六、撮合假设（仿真，非券商费率）

- 股票：双边佣金 5bp 最低 5 元；卖出税 10bp；其他 1bp；滑点 10bp；整手 100
- ETF：双边佣金 5bp 最低 5 元；卖出税 0；滑点 5bp
- 成交基准 = 下一交易日开盘价 ± 滑点，限当日高低区间
- 一字涨停买单/一字跌停卖单/停牌/零量 → 零成交
- 最大成交量 = 当日成交量 5% 向下取整一手
- 止损/目标价只提醒，不自动下单
