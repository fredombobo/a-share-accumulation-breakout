# 策略评分标尺 v0（从 2 分到 9 分）

> 目的：把「提高策略分」变成**可证伪的门禁**，而不是期望或话术。
> 适用：`accumulation_breakout`（AB-Screener）及其后续研究假设。
> 状态：v0 · 2026-09-14 · 由工程侧维护；研究结论必须引用本文件的门禁编号。

## 0. 分数定义

| 分数 | 含义 |
|---|---|
| 2 | 有完整系统与诚实流程，但条件收益/净成本证据为零或为负（**当前基线**） |
| 4 | 测量与数据底座可信：PIT/退市/成本/多重检验纪律齐全，能稳定产出可信的否定 |
| 6 | 单个预登记机制：在**从未看过的 OOS** 上，2× 成本后正期望且下界 > 0，稳健门全过 |
| 8 | 2–3 个弱相关机制的组合：组合层净 Sharpe 0.8–1.2、回撤受控、容量明确、前瞻一致 |
| 9 | 8 分全部成立 + 3× 成本仍正 + 独立数据/市场复制 + ≥12 个月前瞻实盘一致 + 抗衰减 |

**评分只升不降，除非出现反证**：任何门禁失败都必须保留证据并降回对应分数。

## 1. 九道门禁（每道都必须有可复算工件）

| 编号 | 门禁 | 通过标准（预定义，不许事后改） | 工件 |
|---|---|---|---|
| G0 | 数据与测量 | 全历史 PIT 可用时点；退市/停牌/涨跌停/复权完整；成本与冲击模型校准；行情分区 manifest 可复算 | 数据审计报告 + `dataset_partitions` 指纹 |
| G1 | 机制与预登记 | 有经济学/行为学机制说明；研究开始前冻结假设、样本、参数网格、成本与阈值 | 预登记 JSON/MD + SHA-256 + trial ledger |
| G2 | 条件信息 | 事件对匹配对照的条件收益差：按事件日聚类 95% CI 下界 > 0，且显著优于伪事件零分布 | 事件研究报告（`scripts/event_study_matched.py` 产物） |
| G3 | 样本外 | ≥2 年独立 OOS（含至少一段熊市），开发期从未查看；只看一次 | OOS 报告 + 输入哈希 |
| G4 | 稳健性 | PBO < 10%；DSR（按试验数 deflate）≥ 0.95；MinTRL 覆盖 ≥1；参数 ±20% 扰动不崩；去掉最好 5% 交易仍正 | 统计块报告 + 扰动/消融矩阵 |
| G5 | 成本与容量 | 2× 成本为正，3× 成本不破；明确 ADV 参与率上限与容量估计 ≥ 目标资金 5–10 倍 | 成本压力 + 容量模型报告 |
| G6 | 前瞻证据 | Shadow 观察 ≥6 个月、实盘/模拟成交滑点与模型偏差 <30%；成交率与不可成交（涨跌停）如实记录 | 前瞻 store + 对账报告 |
| G7 | 独立复制 | 换数据源/换市场/换制度阶段仍显著；至少一次由不同实现复算通过 | 复制报告 |
| G8 | 组合与风险 | 波动目标/中性化/相关性约束；最大回撤、行业暴露、尾部有预算且可解释 | 组合政策 + 风险快照 |

## 2. 分数映射

- 通过 G0 → **4 分**
- 通过 G0–G4（单机制） → **6 分**
- 再通过 G5、G8（组合层） → **8 分**
- 再通过 G6、G7 且 3× 成本仍正 → **9 分**

未达 6 分之前，**禁止**：宣称 edge、上线实盘、把研究参数写进每日选股、对失败假设调阈值重跑。

## 3. 预定义止损（kill criteria）

任一条件出现即终止该假设并归档失败证据，不得微调后重试：

1. G2 条件收益差 95% CI 下界 ≤ 0 且点估计 ≤ 0；
2. G3 OOS 净 Sharpe < 0.3 或 OOS 交易数 < 100（独立事件口径）；
3. G4 PBO > 20% 或参数 ±20% 扰动后符号翻转；
4. G5 2× 成本后期望 ≤ 0；
5. G6 前瞻滑点/成交率与模型偏差 > 30%；
6. 同一假设的试验次数超过预登记上限（默认 ≤ 5）。
