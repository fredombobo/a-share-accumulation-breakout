# Lab 可信报告与任务恢复实施计划

1. 用测试锁定活动任务优先返回、页面挂载恢复、立即轮询、焦点刷新和单定时器清理。
2. 增加 v11 增量迁移，持久化任务请求、阶段、进度、检查点、结果、报告和版本指纹。
3. 把 Lab 工作流拆成 IS、OOS、WF、双基线、门禁、报告与候选隔离阶段，每阶段事务性保存。
4. 固定 IS 净成本第一名为主候选，实现 OOS/WF/双基线的纯函数门禁及边界测试。
5. 扩展状态、报告历史、报告详情和下载 API，并定义对应 TypeScript 类型。
6. 在 Lab 页面恢复任务状态，展示一页可信报告和人话阻断原因；切页、切标签和刷新均可恢复。
7. 迁移无可信报告的旧活动参数为 `legacy_unverified`，确保活动权重、A 池和订单不读取隔离候选。
8. 运行相关 Pytest、Ruff、Mypy、前端构建和浏览器验收；记录证据、限制与回滚方式。

影响文件以 `ab_screener/research/`、`ab_screener/data/migrations_v2.py`、`web/backend_app.py`、`web/frontend/src/`、`tests/` 和相应文档为主，不进行无关重构。
