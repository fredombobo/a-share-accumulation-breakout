# 资金热力图双向展示设计

日期：2026-08-08

## 目标

- 最新交易日资金热力图显示全部非零行业，不能因按净额降序截断而只显示流入。
- 流入保持红色，流出保持绿色，矩形面积继续表示净额绝对值。
- 鼠标悬停卡片使用深色背景和浅色文字，确保浅色、深色主题下都有足够对比度。

## 数据与接口

`GET /api/money-heatmap` 从最新交易日行业净额中排除零值后返回全部记录。记录按净额绝对值降序，使主要流入和主要流出都优先排列；`net_wan` 保留正负号，`value` 保持绝对值。

保留现有响应结构：

```text
{trade_date, total_wan, items: [{name, value, net_wan}]}
```

## 前端表现

- ECharts treemap 使用全部 `items`。
- 正值使用红色，负值使用绿色。
- 小面积矩形允许 ECharts 自动省略标签，但悬停仍展示行业、方向、净额和日期。
- tooltip 背景继续使用高不透明度深色，文字固定为浅色 `#f8fafc`；不再继承浅色主题的黑色正文色。
- 负值提示标题显示“净流出”，数值显示绝对值；正值显示“净流入”。

## 验收

- 固定数据同时包含正负行业时，接口响应同时包含两类，且不遗漏非零流出行业。
- 页面同时出现红、绿矩形。
- 正负行业 tooltip 均为浅色文字，方向文案正确。
- 既有 API 契约、总览页面、生产构建和相关测试通过。
