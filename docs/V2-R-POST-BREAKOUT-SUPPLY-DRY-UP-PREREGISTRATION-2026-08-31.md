## 2. 单一经济机制

机制 ID：`POST_BREAKOUT_SUPPLY_DRY_UP_V1`

预期版本：`post-breakout-supply-dry-up-v1.0.0`

经济假设：真正完成吸筹的股票在严格放量突破后，次日不应依赖更大的换手维持价格。
如果新增卖盘已经被吸收，确认日成交量应低于突破日，但收盘仍被市场接受在原箱顶
之上，并位于确认日价格区间上半部。假突破则更容易在次日跌回箱体，或需要持续放量
才能勉强维持。

该机制不放宽原始信号，只改变确认时点：

1. `t0` 必须先满足冻结的 `BASE_STRICT_BREAKOUT_V1` 全部条件；
2. `t1` 必须是交易所日历中 `t0` 的下一交易日，停牌或缺少该日 K 线即拒绝；
3. `close(t1) > box_high(t0)`，确认价格仍被接受在原箱顶之上；
4. `volume(t1) < volume(t0)` 且两日成交量均为正，表示突破后供给/换手衰减；
5. `CLV(t1) = (2×close-high-low)/(high-low) > 0`，确认日收于日内区间上半部；
6. 信号时点从 `t0` 推迟到 `t1` 收盘，最早只能在 `t2` 可交易日开盘成交。

边界 `volume ratio < 1` 与 `CLV > 0` 分别来自“不再需要更大换手”和“收盘位于
日内中性点上方”的方向定义，不形成可搜索阈值。机制参数搜索固定为 `none`。
缺失 OHLCV、零振幅、非正成交量、非相邻交易日、身份不匹配均 fail-closed，
不插值、不退回原突破日成交。
