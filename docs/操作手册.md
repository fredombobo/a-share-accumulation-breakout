## 一、日常选股（每天用）

### 启动
1. 双击 `一键启动.bat`
2. 浏览器自动打开 `http://127.0.0.1:8000/`
3. 点页面上的 **「扫描」** 按钮
4. 等 5~15 分钟出结果

### 看结果
| 你看到的 | 含义 |
|----------|------|
| **A 池** | 严格筛选，优先看 |
| **B 池** | 放宽观察，不当主推 |
| **A 池空 + 显示「防守」** | 市场弱，正常风控，不是坏了 |
| 数据日期旧 | 再跑一次一键启动做同步 |

每只股票附带交易卡片：止损价、目标价、建议仓位。

### 停止
双击 `停止.bat`，或 Ctrl+C 关窗口。

## 二、策略实验室（每周/每月迭代）

### 网页操作
1. 打开 `http://127.0.0.1:8000/`
2. 进入 **「🧪 策略实验室」** 页
3. 选方案 A（箱体突破）或 B（五步抓主升）
4. 点 **「优化」**
5. 等待完成（600 只约 30 分钟，全市场 2 小时+）
6. 查看排行榜：盈亏比 PF、胜率、最大回撤
7. 查看 IS/OOS 对比：OOS PF ≥ IS PF × 0.8 才算通过

### 命令行操作
```bash
cd E:\CODEX\Stock_selection\accumulation_breakout

# 方案 A 优化（600只股票，采样步长10）
C:\Python314\python.exe run_optimize_plan.py A 600 10

# 方案 B 优化
C:\Python314\python.exe run_optimize_plan.py B 600 10

# WF复核 + 参数播种 + 擂台赛
C:\Python314\python.exe pipeline_seed.py A
```

### 当前已验证结果
| 方案 | IS PF | OOS PF | OOS/IS | 结论 |
|------|-------|--------|--------|------|
| A | 1.534 | 1.464 | 0.95 | 通过，已注册 active |
| B | 1.608 | 0.983 | 0.61 | 淘汰 |

## 三、参数管理（自动回灌）

优化通过后自动写入数据库，无需手动操作。

### 状态流转
```
candidate（候选）→ active（现役）→ retired（淘汰）
```

| 状态 | 触发条件 |
|------|----------|
| active | IS/OOS 验证 Top1 |
| candidate | IS/OOS 验证 Top2-3 |
| 晋升 | candidate PF ≥ active × 1.2 且回撤不劣 |
| 淘汰 | active 连续 4 周退化 |

### 权重回灌
active 参数的 OOS PF 作为权重乘到选股排序分上：
```
最终得分 = 形态分 × active参数PF权重
```

### 查看当前参数
```bash
C:\Python314\python.exe strategy_store.py --weights
```

当前 active：`vol_ratio=1.8, strong_reset=4, exit_window=7, stop=7%`，权重=1.464

## 四、数据维护

### 日常同步
一键启动时自动增量同步，无需手动。

### 历史扩容（需有效 Token）

**第一步：更新 Token**
1. 去 https://tushare.pro 个人中心复制新 token
2. 打开项目目录下 `.env` 文件
3. 替换 `TUSHARE_TOKEN=` 后面的值

**第二步：跑扩容**
```bash
# 先停掉 Web 后端（避免数据库冲突）
C:\Python314\python.exe sync_history.py
```
- 断点续传，约 2~4 小时
- 目标：3 年日线（≥720 交易日）

**第三步：验证**
```bash
C:\Python314\python.exe sync_history.py --check-only
```

## 六、常见问题

| 问题 | 解决 |
|------|------|
| A 池为空 | 看是否显示「防守」，是=正常风控 |
| 数据日期旧 | 再跑一次一键启动 |
| Token 报错 | 去 tushare.pro 换新 token 更新 .env |
| 端口 8000 被占 | 先双击停止.bat，再启动 |
| 扫描很慢 | 首次建库 30~90 分钟，日常 5~15 分钟 |

## 七、系统架构简图

```
用户 → Web UI (:8000)
         │
         ├─ 扫描 → run_screener.py → signals.py → A池/B池
         │                                    ↑
         │                        scoring.py (读取active权重)
         │                                    ↑
         └─ 策略实验室 → optimizer.py → walkforward.py
                           │              │
                           ↓              ↓
                     strategy_store.py → SQLite (strategy_params)
                           │
                     weekly_arena (擂台赛)
```

闭环：选股 → 回测优化 → 样本外验证 → 参数注册 → 权重回灌 → 选股
