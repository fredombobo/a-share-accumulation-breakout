# 横盘吸筹突破系统操作手册

> 项目：`accumulation_breakout` / AB-Screener
>
> Web：`http://127.0.0.1:8001/`
>
> 边界：研究辅助，不连接券商，不自动交易。

## 一、每天怎么用

1. 双击 `一键启动.bat`。
2. 检查顶部行情日期；过期时点“更新”。
3. 点“扫描”，等待进度完成。
4. 查看 A 池，B 池只作观察。
5. 资金热力图分别核对流入 Top 10 和流出 Top 10。
6. 在候选卡点“查看详情”或“AI 评测”。

个股 AI 首先读取本地形态、量价、资金与财务证据。外部模型只有用户点“生成 AI 文字解读”才会调用；未配置时按钮直接禁用并显示能力状态，不影响本地评测。

## 二、专业回测怎么用

1. 进入“专业回测”。
2. 选择板块，或输入至少 20 只股票代码；空选代表当前全市场。
3. 调整参数模式：固定、范围步进或离散值。默认横盘最长天数为 60 至 200，步长 20；“交易日采样间隔”是决策截面的日期间隔，越小越慢，默认 10。
4. 点“检查参数空间”。确认组合数、股票池哈希、动态预热与研究窗口；超过 512 组需确认长耗时，超过 5,120 组会拒绝。
5. 点“启动专业回测”。任务在服务端持久化，刷新或切页后仍可恢复；IS/OOS 分片与组合会计会持续更新服务端心跳。
6. 完成后按顺序阅读：人话结论、OOS、WF、随机/均线基线、2 倍成本、独立路径排行榜。

结论“值得另行预登记复验”也不代表晋级。网格永远不会自动改变 A 池、生产参数或任何订单。

## 三、参数含义

| 参数 | 含义 |
|---|---|
| 横盘最短/最长天数 | 箱体候选持续的交易日范围 |
| 箱体最大振幅 | 对横盘宽度的约束 |
| 突破量 / 箱体均量 | 突破日相对箱体平均成交量 |
| 突破量 / 前 5 日均量 | 放量的第二重确认 |
| 突破日涨幅上下限 | 排除过弱或异常跳涨 |
| 建仓量 / 前 5 日均量 | 二次出货基准识别所用量能 |
| 止损比例 | 保守退出约束 |
| 止盈比例 | 从买入后的下一交易日起检查；与止损同日触发时优先止损 |
| 最长持有天数 | 到期退出的真实持仓期限，可固定或步进搜索 |
| 二次出货观察窗 | 累计量触发退出检查的窗口 |
| 强势日清零根数 | 连续强势后重新计量的根数 |

最长持有与二次出货观察窗是两个独立参数。排行榜按精确 IS+OOS 权益路径去重；“等效参数”用于披露有多少名义参数实际产生同一结果，不能把重复路径当成额外稳定性证据。采样间隔大于 1 的结果只属于抽样研究，正式逐日复验使用步长 1。

## 四、股票池与时点

行业来自当前 `stock_basic` 快照。系统会冻结具体代码列表和 SHA-256，但不会宣称当前分类等于历史分类。收盘信号最早只能在下一可交易日开盘成交；PIT 数据只允许 `available_at <= decision_at`。

## 五、筹码条件

筹码插件入口已经保留，但当前显示“待预登记，不可加入正式网格”。必须先确定经济机制、字段、缺失值和时点口径，再通过测试解锁；缺数据默认阻断。

## 六、维护和验收

```powershell
python easy_start.py
python sync_daily.py
python run_screener.py --top 15 --days 260 --workers 0
powershell -ExecutionPolicy Bypass -File scripts/quality_gate.ps1 -Strict
```

发布验收至少核对：OpenAPI 无 `/api/paper` 和 `/api/lab`、有 `/api/backtest` 与 `/api/ai-review`；前端只有每日选股和专业回测导航；`LIVE_TRADING_ENABLED=false`；全量质量门通过。

## 七、常见问题

| 问题 | 处理 |
|---|---|
| A 池为空 | 核对是否处于防守环境，以及数据和扫描日期 |
| 回测提示组合过多 | 增大步长、减少离散值或先固定次要参数 |
| 板块少于 20 只 | 合并多个板块或指定更多股票 |
| AI 模型未配置 | 继续使用本地评测；需要时再配置外部模型 |
| 任务切页后不见 | 回到专业回测，页面会读取服务端最近任务 |
| 端口 8001 被占 | 先停止旧实例，再从本项目重启 |
